# 🔐 Login System

A basic authentication flow built with PHP sessions — the foundation every real app needs.

**🔗 Live:** [ankitregisteration.xo.je/login-system](https://ankitregisteration.xo.je/login-system/)

## Features
- Secure login with PHP sessions
- Password handling with hashing
- Session-based access control

## Tech Stack
`HTML` `CSS` `PHP` `MySQL`

## Run locally
```bash
git clone https://github.com/Ankit-4234/login-system.git
cd login-system
# import the included .sql file into MySQL, then serve with a PHP server
php -S localhost:8000
```
